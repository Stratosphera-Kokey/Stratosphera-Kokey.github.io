What I Learned in IT111

Module 1: History of Computing

One important development in computing history was the invention of the microprocessor. It placed the CPU onto a single microchip, making computers smaller, faster, and more affordable. This development helped make personal computers possible and allowed people to use computers at home, school, and work.

Module 2: Computer Systems

When I create my portfolio website, the computer helps me write code, organize files, and view the final result.

  • Input: I type HTML and CSS code using my keyboard.
  • Processing: The CPU processes the instructions and runs the browser.
  • Storage: My website files are saved on my computer.
  • Output: The monitor displays my website through the browser.

These four functions help me create, save, edit, and view my portfolio.

Module 3: Connected World

When someone visits my portfolio website, their browser sends a request through the Internet using a protocol such as HTTPS. The server receives the request and sends the website files back. The browser then displays the webpage on the visitor's screen. An IP address helps identify the destination of the data, allowing the request to reach the correct server.

Module 4: Cybersecurity

To protect my personal information and online identity, I should follow these practices:

  • Use strong passwords: Create passwords that are difficult to guess.
  • Use different passwords: Avoid using the same password for multiple accounts.
  • Enable multi-factor authentication: Add another layer of security to my accounts.
  • Avoid suspicious links: Do not click unknown links that could lead to scams or steal personal information.
  • Keep software updated: Install updates to help protect my computer from security threats.

Following these practices helps keep my accounts, personal information, and devices safer online.
